## Recorder (`lab/opps/record.py`)
Each hand record has two new lab-only fields, taken from the engine's full game state (the bot never sees them):
- `opp_hole3`: the opponent's 3 dealt hole cards, on **every** hand (fold hands too).
- `opp_dis`: the card(s) they discarded (dealt but not held at the end); `[]` if no discard happened.
Old fields (`id seat hole3 hole board opp delta h rv`) are unchanged. Older files lack the new two: use `rec.get("opp_hole3")`.
`hand_record(h, truth=None)` takes the new fields as an optional argument; `to_hand_state` is unchanged.
Test: `tests/test_record_truth.py` (record -> save -> load, fold hands carry `opp_hole3`).

## Score script (`lab/opps/score_compare.py`)
```
.venv/bin/python -m lab.opps.score_compare BEFORE.txt AFTER.txt     # both = lab.eval --out files, locks ON
```
Per bot: score before -> after, diff, SE. Overall = unweighted mean over shared bots. `DROP-score` if overall is lower by > 2 SE,
else `KEEP-score`. Exit 0 = KEEP, 1 = DROP. It reuses `lab.eval.LINE` for the line match.
SE caveat: it comes from the summary line's "match score x ± se over N matches", which is the SE over matches (not over pairs);
the two files are independent runs, so SEs add in quadrature. The summary lines hold no per-pair scores, so this is what is available.
Real-file check, `logs/g/recheck/pool_t2.txt` -> `pool_t3.txt`: overall 0.507 -> 0.590, diff +0.083 ± 0.025, KEEP-score.
Test: `tests/test_score_compare.py` (5 tests incl. the real files).
