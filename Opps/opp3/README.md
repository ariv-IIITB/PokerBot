# Heads-up pokerbot

Stdlib + NumPy only. No file writes, no network, no threads. Never raises, never returns an illegal action.

## Layout
- `player.py`        tournament entry point. Adapter for the MIT-pokerbots skeleton API (`handle_new_round`, `handle_round_over`, `get_action`). **If your starter code differs, only this file changes.**
- `pb/`              engine-independent bot
  - `evaluator.py`   vectorised 5-7 card hand evaluator (tested against a brute-force reference)
  - `equity.py`      Monte-Carlo equity vs a weighted opponent range
  - `tables.py`      preflop equity of all 169 hand classes (generated by `tools/gen_tables.py`)
  - `ranges.py`      opponent range tracking, Bayesian update after every observed action
  - `opponent.py`    smoothed stats: open/3-bet/defend rates, bet freq, fold-to-bet, river bluff rate
  - `strategy.py`    preflop/postflop decisions, sizing, bluff frequencies, legalisation
  - `timing.py`      time-bank manager (full / lean / panic modes)
  - `brain.py`       ties everything together, infers opponent actions, safety wrapper
- `sim/`             local engine (MIT-style rules), baselines, match runner
- `tests/`           evaluator, engine, brain fuzz/timing, adapter tests (fake skeleton included)

## Commands
    python -m unittest discover -s tests            # all tests
    python -m sim.match --a brain --b tag --hands 400 --matches 10
    python -m sim.match --a brain --b station --matches 20 --procs 4
    python -m sim.match --a brain --b mypkg.mymod:MyBot      # any bot with the Brain interface
Baselines: random call fold shove maniac tag nit lag station. Variants: `brain:fast` (300 samples), `brain:nofold` (fold-out off).
Options: `--dup bot|seat` (duplicate-deal style), `--bank` (time bank s per 400 hands), `--procs`.

## Behaviour summary
- Equity vs the *modelled* range (not a random hand), compared with pot odds plus a margin.
- Range narrowing: each opponent action reweights all 1326 combos by P(action | hand strength).
- Value bets sized by equity; bluff/semi-bluff frequency scales with measured fold-to-bet.
- Opponent stats start from balanced priors and are reset every match.
- Time: ~30-50 ms/hand measured locally (budget 150 ms/hand). Under 2 s of bank left it plays check/fold only.
- Fold-out: once the lead exceeds the worst-case blind cost of the remaining hands, it checks/folds everything (cannot lose the match). Disable with `Brain(fold_out=False)`.

## Known limits / things to verify against the real engine
- The local engine is an approximation. Check raise bounds, blind order, button alternation, and whether opponent cards are shown at showdown.
- Duplicate-deal format details are not known; the bot does not depend on them.
- Tune in `strategy.py` (thresholds) and `opponent.py` (priors); re-run matches after every change.
